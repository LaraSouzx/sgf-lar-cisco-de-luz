# Sistema de Gestão Financeira — Lar Beneficente Cisco de Luz

Sistema web para controle financeiro do dia a dia de uma organização sem fins lucrativos, desenvolvido como projeto de extensão universitária.

## Sobre o projeto

O **Lar Beneficente Cisco de Luz** é uma OSC em Caucaia (CE), ativa desde 2017, que oferece atendimento gratuito a crianças, jovens, adultos e idosos. A responsável pela instituição administra sozinha toda a parte financeira e de prestação de contas, sem apoio de contador e sem conhecimento prévio de contabilidade — mas com a obrigação legal de prestar contas.

Este projeto entrega um site simples e responsivo para registrar entradas e saídas, categorizar lançamentos, controlar doadores e gerar relatórios mensais exportáveis, reduzindo o trabalho manual e o risco de erro na prestação de contas.

## Stack técnica

- **Frontend:** React + TypeScript
- **Backend:** Supabase (Auth, Postgres, Storage) — sem servidor próprio

## Escopo do MVP

**Incluso:**
- Lançamentos (entradas/saídas) com categorias
- Cadastro de doadores
- Relatório mensal exportável
- Login e backup automático

**Fora do escopo (por ora):**
- Emissão de nota fiscal / integração com Receita Federal
- Múltiplos níveis de permissão de usuário
- Conciliação bancária automática
- Gráficos analíticos avançados
